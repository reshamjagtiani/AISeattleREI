The map results below (parcel, zoning boundary, sewer/storm/water mains, electric poles & lines, trees) are queried live from the City's GIS servers every time you run a search. The regulatory numbers baked into this tool's logic — HB 1110 unit caps, SMC 23.44.010.C lot-coverage percentages, and SMC 23.44.090 setback distances (renumbered from 23.44.014 as of a January 2026 code reorganization) — were verified against the City's published code summaries as of July 23, 2026 and are a static snapshot: they will not update automatically if the code is amended after that date. Seattle's Neighborhood Residential rules have changed more than once recently — always cross-check current standards directly with SDCI, SPU & Seattle City Light before relying on this for a purchase, design, or investment decision.

City of Seattle addresses only — this tool queries Seattle & King County systems and won't return meaningful results for other cities. Side sewer sharing — verify with the official card

This tool does check SPU's side-sewer connectivity data for a possible shared lateral automatically — if it finds one, you'll see a flag above. But that check can only ever be a best-effort lead, not a confirmed verdict: the public data records which pipe connects to which, but never who owns each private branch, so it can't fully distinguish a lateral genuinely shared with the lot next door from two branches of this same lot's own plumbing. Ownership and any recorded easement or agreement only exist on the scanned side sewer card on file with SPU. If you're serious about this lot, pull the card and confirm before you assume anything either way.

Notes & how to get real flow/pressure numbers
The public GIS layer includes diameter, material, and install year — but not flow rate or pressure, and those aren't published on any map. For real numbers, request a Water, Drainage & Wastewater Availability Certificate (WAC) from SPU — their engineering review (and, for fire-flow-sensitive projects, an actual hydrant flow test) is the authoritative answer. To request one: create an account at the Seattle Services Portal, choose "Public Utilities – Development Services" → record type "Water Availability Certificate," enter the project address and your contact info, a short project description, and upload a site plan (the one required document). SPU emails back if they need more, then sends the WAC by email — no published fee or turnaround time is posted, so ask up front when you submit. More detail on SPU's own WAC page. In the meantime, main diameter here is still your first clue: a 4" main feeding a 6-unit project is a very different conversation than an 8" one.

Notes & data limitations
Pole locations, heights, line routes, and structures come from Seattle City Light's public GIS. What is not public: transformer sizes, existing load on the circuit, and wire clearance heights — those only come out of City Light's engineering review. If a pole sits on your frontage, budget time for that conversation before finalizing height or placement.

The list above is individual tree points (street trees + city-managed trees) — not a canopy coverage percentage. Seattle's tree canopy data is only published aggregated to large areas (50-acre hexagons, council districts, census tracts) — the City has never published a parcel-level canopy % dataset, so there's no live source this tool can query for "X% canopy on this specific lot." ADUniverse's per-property canopy percentage comes from its own one-time internal GIS overlay of the City's 2016 tree canopy assessment against individual parcels — not a live public API — so for that specific number, check ADUniverse's property search directly with this address.
Notes & data limitations
From the city's combined tree inventory (street + city-managed + some private trees). Coverage of trees on private lots is incomplete, and the inventory doesn't flag "exceptional trees" — under Seattle's tree ordinance, trees over certain size thresholds can restrict where you build and can't just be removed. Cross-check on the city's ADUniverse property search and get an arborist survey before locking a site plan.
